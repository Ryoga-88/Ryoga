# RyogaのBlog図解

本文で伝えたい一つの関係を、短い日本語と簡潔な形で示す。見た目をそろえることと、本文の主張を正しく伝えることを両立する。

## 参照と型の選択

初回は [references/style-evidence.md](references/style-evidence.md) で実例と根拠を確認する。制作時は [references/diagram-specs.md](references/diagram-specs.md) から題材に合う型を選ぶ。人物の気持ちや場面を表す線画は `$ryoga-blog-images` の範囲。

## 本文から図へ

1. 本文・メモから、図で伝える主張を1文にする。比較する対象、順序、時点、軸の意味を抽出する。図を加えても理解が増えないなら省略する。
2. 根拠を「本人の経過記録」「考え方を整理する概念」「実測・調査データ」から判断する。未確認の期間、量、成果、因果関係を図へ追加しない。
3. 型を選ぶ。順序はフロー、経過はタイムライン、二つの観点は四象限、時間に沿う関係は曲線、研究の段階変化はパネル図を候補にする。
4. ラベルを本文と同じ語彙で短くし、図だけを見ても対象と関係が分かるようにする。主張を変えない範囲で文章を簡潔にする。
5. 正確な日本語・矢印・軸は、SVGや標準的な作図・プロットツールで確実に描く。意味や数値を画像生成任せにしない。依頼が「作成」なら仕様案だけで止めず、編集可能なソースと閲覧用画像まで作り、実画像を確認する。

仕様や構成案だけを依頼された場合は、その成果物で完了し、描画や画像生成は実行しない。

## 見た目の初期値

- 白背景、黒〜濃いグレーの日本語サンセリフ。図そのものに必要なラベルを中心にし、周囲のタイトル・副題・解説文・注意書きは自動で足さない。説明は本文で伝え、図には関係が分かる最小限の文字を置く。
- 横3:2を基本にし、タイムラインや比較行では横へ広げてよい。主張とラベルが収まる比率を優先する。
- 大きな余白と細い軸・枠。白い箱、黒〜灰の矢印、少数の線・点で構成する。装飾の影や立体表現は足さない。
- 比較グラフは青と橙が基本。3系列目が必要なら緑も使える。色の役割はその図内で決め、別記事まで固定しない。線種、ラベル、位置も使って区別する。
- 定性的な曲線は左・下の軸を中心にし、数値目盛りとグリッドを省く。「今」「これから」「少なめ」「多め」など、関係に合う言葉を置く。四象限やパネルには必要な枠・区切り線を使う。
- 凡例は曲線やラベルと重ならない位置へ置く。説明を足すために図の外周を文字で埋めない。
- 集合の重なりを強調するときは、注目する共通部分に色を付け、そこから引出線・矢印を伸ばして、白い余白に要点を書く。重なりの上に大きな文字や白い箱を載せて、関係を隠さない。

## 概念と記録を区別する

概念図の曲線や点の高さ・交点・位置は、実測や将来予測に見せない。数値がない場合は数値を作らず、概念と実測の違いを制作時に確認する。「分野のつながりを表す概念図」「〜を予測するものではありません」などの定型的な説明・否定の注記は、図中にも図外にも自動で足さない。必要な背景は本文で自然に説明する。「必ず増える」「続ければ成功する」といった本文にない保証を加えない。

本人の経過は本人が確認した時期を使う。タイムラインを読みやすく等間隔に配置するなら、実際の日数の比率を表すものかを明確にする。個人の記録を一般的な効果・回復期間に変換しない。

実測データが渡された場合は、実際の値・単位・出典・集計条件を使う。比較に必要な目盛りや誤差表示を保持し、概念図の見た目のために削除しない。データ未入手なら、描ける構造まで進めて不足を伝える。

## 出力と確認

編集可能なSVGまたは作図ソースと、掲載用PNGを渡す。ツール制約で一方を作れない場合は実際に作れた形式と制約を明示する。推奨の制作寸法・配色は仕様集を参照する。

- 本文・図・キャプションの主張が一致し、矢印が意図しない因果や自動的な成功を示していないか確認する。
- 日本語の文字化け、文字・線の重なり、見切れ、長すぎる注記がないか、出力画像を開いて確認する。
- 記事幅約620pxとスマホ幅約375px相当で確認し、小さすぎるラベルは拡大・短文化する。読めない情報は本文へ移すか図を分ける。
- 色だけに依存せず区別でき、数値・時期・凡例・前提に未確認の補作がないか確認する。

本文で関係を説明した直後に図を置くことを候補にし、図の枚数は固定しない。図ごとのキャプションは自動で添えず、依頼された場合に短い案を渡す。図の周りの文字が不要と指定された場合は、削ったタイトル・説明・注記を図外のキャプションとして再掲しない。出典や数値の条件は、必要に応じて本文の該当箇所で伝える。
