## 共通点と変化

2026年の3本は、です・ます調を軸に「僕」「自分」で現在の考えを話す。短い段落、日常的な見出し、少量の装飾で、考えが少しずつ進む。H2は3〜5個だったが、今後の節数の指定にはしない。顔文字の使用例も、本人らしさを再現する必須条件にはしない。

IJCNN記事は「私」を使い、正式な挨拶や展望を含む報告調。専門語の強調と学びの箇条書きもある。主題による差、時期による差、本人の今後の好みは切り分けられないため、初期モードを選ぶ参考に留める。

## 構成の選択肢

- 生活の実験：変えたこと → 実際の経過 → 続けやすくした工夫 → 感じた変化と限界 → 次に考えたいこと。
- 価値観：今の関心 → 具体的なきっかけ → 見方の変化 → 今選びたいこと → 残る迷い。
- 研究・活動：身近な背景 → 課題 → 手法・工夫 → 資料で確認できた成果 → 現場での経験 → 次の取り組み。

いずれも編集のための候補であり、節の固定テンプレートではない。

## 推敲の小さな例

以下は新しく作った編集例であり、過去記事からの引用でも、本人の新しい経験の記録でもない。

- 材料：通知を切った後、本人は朝の作業へ入りやすく感じた。作業時間は計測していない。
- 避ける方向：通知を切るだけで、生産性が大幅に上がります。
- 近づける方向：通知を切ってから、朝の作業に入りやすく感じました。作業時間を測ったわけではないので、変化の大きさまでは分かりません。

自分の体感は具体的に残し、測っていない効果を数値や一般則へ変換しない。語尾だけを真似るより、事実・体感・解釈の距離を保つことを優先する。
